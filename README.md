# Pokémon Fusion Dex

A browsable dex of Pokémon fusions, built with React and Vite.

**🔗 Live site: [https://ignasbratelund.github.io/pokemon-fusion/](https://ignasbratelund.github.io/pokemon-fusion/)**

Each row links out to the corresponding entry on [InfiniteFusionDex](https://infinitefusiondex.com/).

## Development

```bash
npm install
npm run dev      # start the dev server at http://localhost:5173/
npm run build    # build for production
npm run preview  # preview the production build locally
```
